# мотисквад

Платформа для поиска единомышленников и первых команд в IT-проекты. Это не сервис найма: здесь нет вакансий, зарплат и платного доступа.

## Что работает

- реальные публичные карточки проектов и участников из MySQL;
- живая статистика активных опубликованных проектов и участников в поиске;
- регистрация по email и паролю с обязательным одноразовым кодом из письма;
- двухфакторный вход: пароль + email-код;
- bcrypt с cost factor 12;
- access JWT на 15 минут в HttpOnly Secure SameSite=Strict cookie;
- ротируемые refresh-сессии на 30 дней, хранящиеся в БД только в виде SHA-256;
- отзыв сессии при выходе и обнаружении неверного refresh-токена;
- строгая Zod-валидация и prepared statements;
- защита от IDOR: профиль привязан к ID сессии, проекты изменяются только с `owner_id` текущего пользователя;
- RBAC для публикации проектов;
- rate limiting для регистрации, входа и проверки кодов;
- Same-Origin проверка мутаций и защитные HTTP-заголовки;
- секреты только в переменных окружения.

## Локальный запуск

1. Создайте MySQL-базу.
2. Скопируйте `.env.example` в `.env.local` и заполните значения.
3. Выполните:

```bash
npm install
npm run db:init
npm run dev
```

## Развёртывание на Beget

Рекомендуемый вариант — Beget VPS/Cloud Server с Docker. В репозитории есть `Dockerfile` и `docker-compose.yml`.

1. Прикрепите домен к серверу и включите HTTPS.
2. Создайте MySQL-базу и почтовый ящик вида `no-reply@ваш-домен.ru`.
3. Скопируйте `.env.example` в `.env.production`. Не добавляйте этот файл в Git.
4. Выполните миграцию схемы из `db/schema.sql` или локально запустите `npm run db:init` с production `DATABASE_URL`.
5. Запустите `docker compose up -d --build`.
6. Направьте Nginx на `127.0.0.1:3000`, включите автоматическое продление TLS-сертификата.

SMTP Beget: `smtp.beget.com`, защищённый порт `465`. Для доставляемости писем настройте SPF, DKIM и DMARC для домена.

## Проверки перед публикацией

```bash
npm test
npm run lint
npm run build
```

Для production обязательно используйте случайные независимые значения длиной не менее 32 байт для `AUTH_SECRET`, `EMAIL_CODE_PEPPER` и `IP_HASH_SECRET`, ограничьте доступ к MySQL сетевыми правилами и настройте резервное копирование базы.
