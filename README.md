# мотисквад

Премиальная адаптивная платформа для поиска единомышленников и первых команд в IT-стартапы. Это не сервис найма: на платформе нет вакансий, зарплат и платного доступа — только начинающие специалисты и основатели, которые хотят вместе создавать проекты.

## Возможности

- два сценария: «Хочу в команду» и «Собираю команду»;
- фильтры по специализации, уровню (без опыта / Junior) и формату;
- каталоги проектов и участников;
- демонстрационные регистрация, вход и личный кабинет;
- адаптивная вёрстка для мобильных и широких экранов;
- собственная canvas-визуализация Career signal.

## Технологии

- TypeScript
- React 19
- Tailwind CSS 4
- Vinext / Vite
- CSS

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

Проверка production-сборки:

```bash
npm run build
```

## Важно об авторизации

Текущая версия — интерфейсный прототип: профиль сохраняется только в `localStorage` текущего браузера. Перед публичным запуском регистрацию по паролю нужно подключить к серверной базе данных, хешированию паролей и защищённым сессиям.
